🧪 Evaluation Script Description

This evaluation script is used to assess the performance of Optical Character Recognition (OCR) models on Tibetan text using the Character Error Rate (CER) metric. The script compares participant-submitted predictions with ground truth annotations and returns a final evaluation score.

📤 Submission File Format

Participants must submit a JSON file containing their predictions. The file should be a list of dictionaries, where each dictionary represents a prediction for one image. Each dictionary must contain the following keys:

  • filename: (string) — The name of the image file (must match the filenames provided in the test annotation file).
  • prediction: (string) — The predicted transcription (in Unicode Tibetan).
  • note:: The number of rows must be same as the TestDataset.

Example Submission File:

[
    {
    "filename": "7-1-415b_2",
    "image_url": "{image url same as in test dataset}",
    "prediction": "ཡིན་པའི་ཕྱིར་རོ། ། དགག་དགྱེའི་གཞིའོ། ། ། གཉིས་པ་ནི། ནང་ཞེ་འགྲས་བདང་ .... "
  }
]

📋 Test Annotation File Format

The ground truth file used for evaluation is also a JSON file structured similarly to the submission file:

  • filename: (string) — File Name of the test image.
  • image_urlLink to the image on web
  • label: (string) — Ground truth Tibetan transcription in Unicode.

Example Annotation File:

[
   {
    "filename": "7-1-415b_2",
    "image_url": "{image url}",
    "label": "ཡིན་པའི་ཕྱིར་རོ། །དགག་དབྱེའི་གཞིའོ། །གཉིས་པ་ནི།ནང་ཞེ་འགྲས་པ་དང་ ....།",
    "source": "karmapa8_test_data"
  }
]

⚙️ Evaluation Process

  1. The evaluator loads both the test annotations and the user submission.
  2. It matches the predictions with ground truth based on the filename.
  3. Both label and prediction are converted to Wylie transliteration using pyewts.
  4. CER is calculated using the evaluate library for each file.
  5. The script outputs the mean CER across all matched samples.
  6. Files without a corresponding prediction are skipped and the count is reported.

📈 Evaluation Metric

The only metric used in this evaluation is:

  • CER (Character Error Rate): Measures the number of character-level errors (insertions, deletions, substitutions) between the prediction and the reference, normalized by the number of characters in the reference.

The lower the CER, the better the model's performance.

🚫 Common Issues to Avoid

  • Make sure all filenames in your submission exactly match those in the test annotation file.
  • Ensure your predictions are in valid Unicode Tibetan.
  • Do not leave predictions empty or missing; unmatched files will be skipped and reduce your evaluated sample size.
