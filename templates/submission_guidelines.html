📤 Submission Guidelines

Please carefully follow these guidelines to ensure your submission is valid and can be evaluated successfully.

✅ File Format

  • Your submission must be in JSON format.
  • The JSON file must contain a list of prediction entries.
  • Each entry should be a dictionary with the following two keys:
    • filename — The name of the image file (as given in the test set).
    • prediction — Your model's predicted Tibetan transcription (in Unicode).

📝 Example JSON Structure

[
    {
        "filename": "img_001.jpg",
        "prediction": "བོད་ཡིག"
    },
    {
        "filename": "img_002.jpg",
        "prediction": "གསུང་བཤད"
    }
]

📌 Important Notes

  • Do not include additional fields like IDs, confidence scores, etc.
  • Do not submit results in CSV, Excel, or text formats — only JSON is accepted.
  • Ensure that the filename values exactly match those in the test annotation file (case-sensitive).
  • Your prediction must be in valid Unicode Tibetan text.
  • Any image files in the test set that are missing from your submission will be counted as missed files and excluded from scoring.

📤 How to Submit

  1. Prepare your JSON file according to the format described above.
  2. Name the file clearly, e.g., submission.json.
  3. Upload your file through the designated platform interface (e.g., EvalAI submission portal).

📊 Evaluation

Your predictions will be evaluated using the Character Error Rate (CER). The lower your CER score, the better the performance.

🚫 Submission Will Be Rejected If:

  • The file is not in valid JSON format.
  • Required keys (filename, prediction) are missing or incorrectly named.
  • Prediction entries are empty or missing for all test files.

For any issues or clarifications, please reach out to the challenge organizers.
